# Outputs

This folder contains maps and summary tables generated by the analysis scripts. All files here are produced automatically — do not edit them manually. Re-running the scripts will overwrite them.

## Files

| File | Produced by | Description |
|------|-------------|-------------|
| `map_plants_per_county.png` | `02_plants_per_county.R` | Choropleth map: number of power plants per county |
| `map_nearby_plants.png` | `03_nearby_plants.R` | Choropleth map: number of power plants within 50 km of each county |
| `map_pm25.png` | `04_pm25_extraction.R` | Choropleth map: mean annual PM2.5 per county |
| `pm25_comparison.png` | `05_comparison.R` | Bar chart comparing mean PM2.5 across plant-presence groups |
